# Pickup Time Logic (Brief)

This is the runtime flow for `pickup_time` in `delivery_summary`.

## Trigger chain (DB -> API handler)

- Source trigger is in `ordelo_datamodels/summary.sql`:
  - `trigger_restaurant_updates` on `delivery_summary` (`AFTER INSERT OR UPDATE OF restaurant_confirmation_status`)
  - trigger function `restaurant_updates_whook()` posts to `/delivery-hooks/restaurant-confirmation-request`
- In `watomation/routers/delivery_hooks.py`, `restaurant_confirmation_flow()` routes by `trigger_reason`.
- When `trigger_reason='restaurant_accept'`, it schedules `_handle_restaurant_accept()` (this is how pickup-time options are kicked off).

## 1) Restaurant accepts order -> pickup options sent

- `watomation/routers/delivery_hooks.py` in `_handle_restaurant_accept()` sends pickup choices to admins.
- Choices are generated by `utils_common/waba_utils/wa_senders.py` in `send_restaurant_pickup_time()`.
- Default options are `+5`, `+15`, `+25` minutes from `delivery_summary.dtts`.
- Callback action used in buttons is `/PickupTime`.

## 2) Admin selects pickup time -> DB update

- `watomation/on_callback_wa_handler.py` in `handle_pickup_time_selection()` handles `/PickupTime`.
- It updates `delivery_summary` with:
  - `pickup_time = selected value`
  - `status = 'unassigned'`
  - `restaurant_admin`, `restaurant_update_dtts`
- Update is gated by `restaurant_confirmation_status = 'restaurant_accept'` to avoid stale/duplicate writes.

## 3) Timeout path if no pickup time selected

- `ordelo_datamodels/jobs_n_functions/process_restaurant_confirmation.sql` runs every 5s.
- If `restaurant_confirmation_status` is `restaurant_unconfirmed` or `restaurant_accept` and `pickup_time IS NULL` past timeout, it sets `restaurant_confirmation_status` to `restaurant_timedout`.
- Timeout uses config:
  - `{rest_ref}_RESTAURANT_CONFIRMATION_TIMEOUT_TIME`
  - fallback `RESTAURANT_CONFIRMATION_TIMEOUT_TIME`
  - fallback default `5` minutes.

## 4) Auto-accept on timeout

- `watomation/routers/delivery_hooks.py` in `_handle_restaurant_timedout()` sets:
  - `pickup_time = dtts + 30 minutes` (Europe/London timezone handling)
  - `restaurant_confirmation_status = 'auto_accept'`
  - `status = 'unassigned'`
- Admins are notified with the auto-assigned pickup time.

## 5) Downstream use

- `pickup_time` is included in rider dispatch payload/message flow (see `docs/dispatch_flow.md`).
- SQL payload wiring for restaurant webhook includes `pickup_time` in `ordelo_datamodels/summary.sql` (`restaurant_updates_whook()` JSON build).
